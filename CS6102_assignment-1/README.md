# CS6102 Assignment 1

This assignment focuses on implementing arithmetic over **GF(16)** in both hardware and software, and then using the implemented multiplier in a higher-level algorithm.

The assignment is divided into three parts.

---

## Part 1: GF(16) Multiplier in Verilog

- Implement a **GF(16) multiplier** using **Verilog**.
- Write a **testbench** to verify the correctness of the multiplier.
- The testbench should validate the output for all valid input combinations in GF(16).
- check `part1/README.md` 

---

## Part 2: GF(16) Multiplier in C++

- Implement the **GF(16) multiplier** in **C++**.
- Compare the results with a **provided optimized GF(16) multiplier**.
- Compare the number of cycles of your implementation using the optimized multiplier.
- check `part2/README.md`

---

## Part 3: expandSK Algorithm

- Using the GF(16) multiplier implemented earlier, implement the **`expandSK`** algorithm.
- Detailed instructions and specifications for this part are provided in: `part3/README.md`
